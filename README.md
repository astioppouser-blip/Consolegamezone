# 🎮 Console Game Zone

## 📌 Deskripsi Proyek

**Console Game Zone** adalah aplikasi berbasis Java Console yang dibuat untuk membantu petugas rental PlayStation dalam menghitung biaya penyewaan dan menampilkan rincian pembayaran pelanggan. Aplikasi ini dikembangkan menggunakan bahasa pemrograman Java melalui Apache NetBeans IDE sebagai bagian dari latihan praktikum Pemrograman Java Dasar.

Aplikasi ini menyediakan dua pilihan konsol, yaitu PlayStation 4 (PS4) dan PlayStation 5 (PS5), dengan tarif sewa yang berbeda. Selain itu, terdapat fitur diskon otomatis, pilihan tambahan minuman, dan pencetakan struk pembayaran.

## ✨ Fitur Aplikasi

- Input nama pelanggan.
- Pilihan konsol PlayStation 4 dan PlayStation 5.
- Perhitungan biaya sewa berdasarkan durasi bermain.
- Diskon 10% untuk durasi bermain minimal 3 jam.
- Pilihan tambahan minuman seharga Rp5.000.
- Tampilan struk pembayaran secara otomatis.
- Pilihan melakukan transaksi baru atau mengakhiri program.

## 💰 Daftar Harga

| Jenis Konsol | Harga per Jam |
|---|---:|
| PlayStation 4 (PS4) | Rp8.000 |
| PlayStation 5 (PS5) | Rp12.000 |
| Tambahan Minuman | Rp5.000 |

**Ketentuan diskon:** Diskon sebesar 10% diberikan jika pelanggan menyewa konsol selama minimal 3 jam.

## 🛠️ Teknologi yang Digunakan

- Bahasa pemrograman Java
- Apache NetBeans IDE
- Java Console
- Scanner untuk input pengguna

## ▶️ Cara Menjalankan Aplikasi

1. Buka proyek **Console Game Zone** di Apache NetBeans IDE.
2. Buka file Java yang berisi method `main()`.
3. Jalankan program dengan menekan tombol **F6** atau memilih **Run Project**.
4. Masukkan nama pelanggan.
5. Pilih konsol PlayStation yang ingin disewa.
6. Masukkan durasi bermain dalam satuan jam.
7. Pilih apakah ingin menambahkan minuman.
8. Lihat rincian pembayaran pada jendela Output.
